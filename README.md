# AXIS — 24H News Intelligence for Students & Gen-Z

> **Zero clickbait. Zero doom-scrolling. Just the signal.**
>
> AXIS is a modern news app designed exclusively for **students and Gen-Z** readers who want to stay informed in **30 seconds**, not 30 minutes. Think of it as your digital newspaper — fast, factual, and built for the way you consume content.

## ⚡ The 30-Second Flash Preview

> **For students who can't give more than 30 seconds** — swipeable news cards that deliver every key story in one glance.

```

│                                     │

│  Geneva Global AI Safety Compact    │

│  ══════════════════════════════════  │
│                                     │
│  💡 KEY TAKEAWAY                    │
│  "Global powers agreed on safety    │
│   boundaries while protecting       │
│   academic open-source weights."    │
│                                     │
│  • Sets mandatory pre-deployment    │

│  ⏱️ 3 hours ago                     │

└─────────────────────────────────────┘

```

### Features

| Feature | Description |
|---|---|
| **Swipeable Cards** | Navigate with arrow keys (← →), spacebar, or tap buttons |
| **30s Audio Summary** | Browser-native text-to-speech reads the card aloud — adjustable speed (1x, 1.25x, 1.5x) |
| **Source Verification Badges** | Every card shows if it's Govt Verified ✅, Agency Verified 🔵, or Unverified Leak 🟡 |
| **One-Tap Deep Dive** | Want more? Hit "Full Detail" for timeline, quotes, and primary documents |
| **Save & Share** | Bookmark for exam prep or copy formatted bullets to WhatsApp/Telegram |
| **Keyboard-First** | Designed for laptop users — no mouse needed |

## 📊 Verification System

Every news dispatch on AXIS carries one of three verification levels:

| Badge | Meaning | Example Sources |
|---|---|---|
| 🟢 **Govt / Official Verified** | Published by a government body or official institution | PIB, RBI, AAI, UN, IEA, MeitY |
| 🔵 **Peer / Agency Verified** | Covered by multiple reputable media outlets or peer-reviewed | Reuters, BBC, Nature, Google Research |
| 🟡 **Trending / Unverified** | Community-sourced or leaked — flagged clearly as unverified | SteamDB leaks, X/Twitter rumors, datamines |

> **AXIS never publishes unverified content without labeling it.** Students can trust the badges before sharing or citing.

## 📝 Content Philosophy

1. **No clickbait titles** — Headlines state what happened, not what you should feel
2. **Source-first journalism** — Every article links to the primary official document
3. **Student-relevant framing** — Every story answers: *"Why should a 19-year-old in college care?"*
4. **30-second rule** — If a student can't get the core story in 30 seconds, we've failed
5. **Verification transparency** — Unverified content is always labeled, never hidden
6. **Zero ads, zero tracking** — Your attention is not for sale
